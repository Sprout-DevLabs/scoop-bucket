# Sprout-DevLabs Scoop bucket

```powershell
scoop bucket add sprout https://github.com/Sprout-DevLabs/scoop-bucket
scoop install sprout
```

Manifests in `bucket/` are generated by [GoReleaser](https://goreleaser.com) on every
[Sprout release](https://github.com/Sprout-DevLabs/sprout/releases). Don't edit them by hand.
